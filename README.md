# 🌸 CodeAlpha - Task 1: Iris Flower Classification

This project is part of my **Data Science Internship at CodeAlpha**.  
In this task, I implemented a **Machine Learning model** to classify Iris flowers into three species — *Setosa*, *Versicolor*, and *Virginica* — based on their morphological measurements.

---

## 📘 Project Overview

The **Iris Flower Classification** is one of the most popular beginner-level datasets in machine learning.  
The objective is to predict the species of an Iris flower given the following input features:

- 🌿 Sepal Length  
- 🌿 Sepal Width  
- 🌸 Petal Length  
- 🌸 Petal Width  

Using these measurements, the model classifies each flower into one of the three categories.

## ⚙️ Workflow

1. **Import Dataset**  
   Downloaded the Iris dataset and imported it using `pandas.read_csv()`.

2. **Data Exploration (EDA)**  
   - Checked missing values and data distribution.  
   - Visualized relationships between features using pairplots and histograms.

3. **Data Preprocessing**  
   - Encoded labels for classification.  
   - Split dataset into training and testing sets.

4. **Model Training**  
   - Trained multiple models (Logistic Regression, KNN, Decision Tree, SVM).  
   - Selected the best-performing model based on accuracy.

5. **Model Evaluation**  
   - Evaluated accuracy using test data.  
   - Displayed confusion matrix and classification report.

6. **Prediction**  
   - Predicted flower species for new data inputs.

---

## 📊 Results

- Achieved over **95% accuracy** using Scikit-learn models.  
- Visualized classification boundaries and model performance metrics.
